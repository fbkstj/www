# 🗣️ 04. 常用語音口語指令庫與 Prompt 手冊 (Voice & Chat Commands)

專門為手部不便打字、視力吃力或年長學員設計的自然語言指令庫。學員只要使用手機或電腦的**語音輸入法**說出以下話語，AI 即可精確執行對應功能。

---

## 🎯 核心語音指令對照表

| 學員說的話 (口語指令) | 觸發情境 | AI 幕後執行的行為 |
| :--- | :--- | :--- |
| **「我操作不便，請幫我操作，但我需要觀看。」** | 學員剛登入並點開課程首頁 | • 將影片畫面置中滿版<br>• 以 1.0x 正常原速流暢播映<br>• 每秒維護連線，完課自動跳下一單元 |
| **「請幫我完成這門課，結束後下載研習證書 PDF。」** | 需要一條龍全套處理 | • 全自動巡航觀看完所有章節<br>• 滿足法定時數門檻 (如 40 分鐘)<br>• 自動作答測驗 100 分<br>• 產出 PDF 證書下載至「下載」資料夾 |
| **「暫停播放」** | 學員想喝水、接電話或暫離休息 | • 立即暫停影片畫面<br>• 停止計時並完整保存當前進度秒數 |
| **「繼續看剛才的單元」** | 學員休息完畢回到螢幕前 | • 一秒接續剛才暫停的時間點恢復播放 |
| **「畫面上跳出警告視窗，幫我關掉。」** | 出現「禁止多重視窗」或確認視窗 | • 呼叫 MCP `handle_dialog` 自動按確定排除 |
| **「這個單元太小聲了，幫我調大聲點。」** | 影音音量微弱 | • 透過 `evaluate_script` 將 `video.volume = 1.0` 調至最大 |
| **「我想看現在修課進度到哪裡了？」** | 了解學習進展 | • 查詢並回報：「目前已完成 4/6 單元，閱讀時數已累計 32 分鐘」 |
