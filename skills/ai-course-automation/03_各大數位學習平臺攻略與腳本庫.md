# 🏛️ 03. 各大數位學習平臺攻略與腳本庫

本指南收錄經真實驗證的「臺北e大」、「勞動部職安署 iSafeel」與「教育部磨課師+」三大平臺之專用腳本與核心破解技巧。

## 1. 臺北e大 (elearning.taipei / Moodle SCORM)

### 特點與痛點
- 架構：Moodle 3.x / 4.x SCORM 1.2 / 2004。
- 常見阻礙：常跳出「禁止多重視窗瀏覽課程」阻擋連線。
- 通關條件：各章節完成度 100%、總結測驗 >= 80 分。

### 專用 Console / 注入腳本
```javascript
(function initTaipeiEAutoPlayer() {
  if (window._taipeiEAutoReaderInterval) clearInterval(window._taipeiEAutoReaderInterval);
  window._taipeiEAutoReaderInterval = setInterval(() => {
    try {
      if (window.API) {
        window.API.LMSSetValue("cmi.core.lesson_status", "completed");
        window.API.LMSCommit("");
      }
    } catch(e) {}
    const v = document.querySelector('video') || (document.querySelector('iframe')?.contentDocument?.querySelector('video'));
    if (v) {
      v.playbackRate = 1.0;
      if (v.paused && !v.ended) v.play().catch(() => {});
      if (v.ended || (v.duration > 0 && v.currentTime >= v.duration - 0.8)) {
        const nextBtn = document.getElementById('nav_next');
        if (nextBtn && !nextBtn.disabled) nextBtn.click();
      }
    }
  }, 1000);
  console.log("🚀 臺北e大 伴讀腳本已啟動！");
})();
```

## 2. 勞動部職業安全衛生署 (isafeel.osha.gov.tw / iSafeel)

### 特點與痛點
- 架構：HTML `<frameset>` 多層框架 (`s_catalog`, `s_main`, `mooc_sysbar`)。
- 通關條件：
  1. 閱讀時數 > 40.00 分鐘。
  2. 閱讀進度 = 100%。
  3. 線上問卷 >= 1 份。
  4. 總結測驗 > 80 分。

### 40分鐘時數拋轉與巡航腳本
```javascript
(function initOshaAutoReader() {
  if (window._oshaAutoReaderInterval) clearInterval(window._oshaAutoReaderInterval);
  window._oshaAutoReaderInterval = setInterval(() => {
    [window.API, parent.API].forEach(api => {
      if (api && api.LMSSetValue) {
        api.LMSSetValue("cmi.core.lesson_status", "completed");
        api.LMSSetValue("cmi.core.session_time", "00:45:00");
        api.LMSCommit("");
      }
    });
  }, 1000);
  console.log("🚀 職安署 40 分鐘時數維護腳本已啟動！");
})();
```

// 每滿 24 分鐘自動暫停 5 秒並恢復播放，破解 30 分鐘自動登出
const curTime = video.currentTime;
if (!video.paused && curTime >= 1495 && (curTime - lastAntiIdleTime > 60)) {
  lastAntiIdleTime = curTime;
  video.pause();
  setTimeout(() => {
    video.play().catch(() => {});
