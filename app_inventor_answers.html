題目 3: 因數計數器

測驗重點： 迴圈與變數計數 (Counter)。找出因數的同時，計算個數。
當 Button_Find.Click do
set count to 0
set str to "因數有: "
for each number from 1 to Box_N.Text by 1 do
if
remainder(Box_N.Text, number) = 0
then
set str to join(str, number, ", ")
set count to (count + 1)
set Label.Text to join(str, "\n總共有 ", count, " 個")

set sum to 0
for each number from 1 to Box_N.Text by 1 do

remainder(number, 2) = 0
then

題目 5: 數字金字塔

測驗重點： 雙層迴圈 (Nested Loop)。利用內層迴圈變數 j 產生連續數字。
當 Button_Draw.Click do
set Label.Text to ""
for each i from 1 to Box_Level.Text by 1 do
set line_str to ""
for each j from 1 to get i by 1 do
set line_str to join(line_str, get j)
set Label.Text to join(Label.Text, line_str, "\n")
