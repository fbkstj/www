1. 工作流全景圖與架構概述

本套自動化流程旨在將長達數小時的課堂側錄影片，透過 Python 腳本結合 AI 語音辨識技術，自動轉化為高質感、具備動態片頭、繁體中文字幕與 YouTube 專屬播放清單的完整線上課程。

01

標準化輸入與裁切

長影片自動分段、FFmpeg 靜音與過低音量偵測，剔除非授課無聲空白。

02

AI 語音辨識與繁體化

Faster-Whisper (CPU int8) VAD 斷句，結合 OpenCC 轉換為台灣習慣繁體用語。

03

單行舒適字幕重構

打破碎片切分，合併為 15~25 字單行長句，停留 3~6 秒，徹底解決閃爍問題。

04

自動壓製與 YT 發布

1080p 動態片頭繪製、ASS 陰影字幕燒錄，搭配 YouTube API 批次自動建置清單。

2. 第一階段：原始檔整理與標準化命名

良好的檔案結構是自動化腳本順利運作的基石。建立規範的目錄與命名習慣可大幅降低後續處理錯誤率。

資料夾結構建議

d:\影片編輯\115-09-07-AI課程\
├── 第01節課_45分鐘分段_000000至004500.mp4
├── 第02節課_45分鐘分段_004500至013000.mp4
├── ...
└── output/
    ├── transcriptions/    # 語音辨識原始 JSON 檔
    ├── subtitles/         # 生成之 SRT 與 ASS 字幕檔
    ├── covers/            # 1080p 片頭圖卡與 4 秒短片
    └── final_videos/      # 最終壓製完成之 MP4 影片
💡 命名關鍵技巧

使用具備明確集數序號（如 第01節課、ep01）的檔案名稱，方便 Python 使用正則表達式（Regex）自動解析與排序。

3. 第二階段：智能無聲裁切與噪音過濾

課堂影片常包含老師思考、寫板書或學生實作的無聲空白段落。過濾這些片段可提高影片節奏與觀看體驗。

FFmpeg SilenceDetect 檢測參數

利用 FFmpeg 的 silencedetect 音訊濾鏡偵測連續無聲段落：

ffmpeg -i input.mp4 -af silencedetect=noise=-32dB:d=1.5 -f null -
參數 建議設定 說明
noise -32dB ~ -35dB 噪音門檻。高於此分貝數視為有聲音，低於則視為靜音。
d (duration) 1.5s ~ 2.0s 持續時間。無聲狀態超過此秒數時記錄時間點。

4. 第三階段：Whisper 語音辨識與高職電機電子群專有名詞注入

為大幅提升 AI 語音轉字幕對**台灣高職電機與電子群課程**專有名詞的精準度，我們在 Whisper 語音辨識階段引入了「領域 context 提示詞 (Domain Initial Prompt)」與「OpenCC 台灣繁體慣用詞對譯庫 (s2twp)」。

🎯 高職電機與電子群 & AI 專有名詞注入詞庫

在語音辨識時，特別針對以下三大類別術語進行提示與修正：

  • AI 與程式開發類：Python、ChatGPT、提示詞 Prompt、LLM 大語言模型、生成式 AI、Gemini、Antigravity、自動化腳本、演算法。
  • 高職電子電機與物聯網類：Arduino、ESP32、微控制器 (MCU)、PCB 印刷電路板、物聯網 (IoT)、感測器 (Sensors)、數位電路、電子學、專題製作。
  • 校園與技職教育類：高職、電機與電子群、實習處、楊梅高中。
⚠️ 重大陷阱：Whisper 提示詞重複幻覺 (Prompt Hallucination)

在使用 Faster-Whisper 時，若傳入過長或過於複雜的 initial_prompt（如將幾十個名詞全部串在一起），一旦遇上影片中**低音量、靜音或老師未說話的空白段落**，Whisper 容易陷入死迴圈，將提示詞重複輸出，導致整集影片字幕壞死（僅剩幾行無效文字）。

精簡高效的 Initial Prompt 注入範例

from faster_whisper import WhisperModel
import opencc

# 1. 初始化模型（CPU int8 穩定性最佳）
model = WhisperModel("medium", device="cpu", compute_type="int8")
converter = opencc.OpenCC('s2twp') # 台灣繁體慣用詞庫（自動將大陸用語轉為台灣習慣）

# 2. 精簡注入「高職電機與電子群與 AI 領域 Prompt」
domain_prompt = "這是台灣高職電機與電子群 AI 應用與實務課堂教學。專有名詞：AI、Python、ChatGPT、Prompt、LLM、生成式AI、ESP32、Arduino、物聯網、PCB、自動化。"

segments, info = model.transcribe(
    "video_path.mp4",
    language="zh",
    initial_prompt=domain_prompt,  # 精簡傳入，防死迴圈
    beam_size=5,
    vad_filter=True,               # 必須啟用 VAD 過濾靜音
    vad_parameters=dict(
        min_silence_duration_ms=1500,
        speech_pad_ms=400
    )
)

# 3. 轉譯並過濾潛在幻覺
segs_data = []
for s in segments:
    tw_text = converter.convert(s.text.strip())
    # 防護機制：過濾包含提示詞抬頭的幻覺字串
    if tw_text and "專有名詞：" not in tw_text:
        segs_data.append({"start": round(s.start, 2), "end": round(s.end, 2), "text": tw_text})

5. 第四階段：字幕重構黃金法則與美學規範

預設語音辨識常輸出 3~5 個字的碎句，導致字幕快速換頁閃爍。必須經過「二次重構」才能達到電視/教學影片的閱讀品質。

原則 1

堅持「單行顯示」

嚴格禁止雙行折行或換行。畫面保持單行，乾淨不遮擋教學簡報內容。

原則 2

長度黃金區間 (15-25 字)

將連續語音片段合併為 15~25 個繁體中文字的自然完整長句。

原則 3

舒適停留時間 (3-6 秒)

每行字幕在螢幕上至少停留 3~6 秒，避免快閃造成觀眾視覺疲勞。

原則 4

高對比視覺美學

採用微軟正黑體、純白文字、深色陰影外框（Outline 3, Shadow 2），確保清晰度。

ASS 字幕樣式配置 (v4+ Styles)

PlayResX: 1920
PlayResY: 1080

6. 第五階段：FFmpeg 自動化壓製與片頭合成

利用 Python Pillow 繪製 1080p 動態封面（標註上課日期與學校資訊），並透過 FFmpeg 將 4 秒片頭與主影片拼接，同時燒錄 ASS 內嵌字幕。

FFmpeg 複合濾鏡 (Filter Complex) 命令範例

ffmpeg -y \
  -i intro_4s.mp4 \
  -i lecture_main.mp4 \
  -filter_complex \
  "[0:v]scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2[v0]; \
   [1:v]scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2[v1]; \
   [v0][0:a][v1][1:a]concat=n=2:v=1:a=1[vconcat][acontat]; \
   [vconcat]ass='subtitles.ass'[outv]" \
  -map "[outv]" -map "[acontat]" \
  -c:v libx264 -preset ultrafast -crf 20 \
  -c:a aac -ar 44100 -ac 2 -b:a 192k \
  final_output.mp4

8. 【核心專題】Google OAuth2 7天 Token 續期與永久認證解決方案

🚨 經典踩坑：為什麼 Refresh Token 在 7 天後突然失效？

在 Google Cloud Console 中建立 OAuth 2.0 Client ID 時，若 GCP 專案的 **「OAuth 同意畫面 (OAuth Consent Screen)」發布狀態保持在『Testing (測試中)』**，Google 安全機制規定發出的 Refresh Token 最長有效期**限定為 7 天**。7 天一到，Token 即被強制撤銷，執行 API 時會拋出 invalid_grant: Token has been expired or revoked 錯誤。

💡 三大核心解決方案 (3 Robust Solutions)

解法 A（推薦）

Google Cloud 專案正式發布 (In Production) —— 免去 7 天限制

登入 Google Cloud Console → 選擇您的專案 → 進入 OAuth 同意畫面 (OAuth Consent Screen) → 將發布狀態 (Publishing Status) 從 Testing 點擊切換為 In Production (正式發布)。

註：若僅供個人或內部測試使用（User Type 為 External 但非公開商業應用），直接發布無須提交 Google 官方安全性人工審查，即可獲得永久有效的 Refresh Token。

解法 B

Python 程式碼自動 Token 續期機制 (Auto-Refresh Routine)

在 Python 程式中，使用 google.auth.transport.requests.Request()，每次發起 API 呼叫前檢查 Token 狀態。若已過期但 refresh_token 仍有效，自動向 Google OAuth 伺服器申請新的 access_token 並回寫更新 yt_token.json：

from google.oauth2.credentials import Credentials
from google.auth.transport.requests import Request
import os

token_path = r"d:\影片編輯\yt_token.json"
SCOPES = ["https://www.googleapis.com/auth/youtube.upload", "https://www.googleapis.com/auth/youtube.force-ssl"]

def get_valid_youtube_credentials():
    if not os.path.exists(token_path):
        raise FileNotFoundError(f"找不到 Token 檔案: {token_path}")
        
    creds = Credentials.from_authorized_user_file(token_path, SCOPES)
    
    # 核心自動續期邏輯
    if creds.expired and creds.refresh_token:
        print("🔄 Token 已過期，正在向 Google API 自動申請續期 (Refresh Token)...")
        creds.refresh(Request())
        
        # 回寫更新後的權限 JSON 檔
        with open(token_path, "w", encoding="utf-8") as f:
            f.write(creds.to_json())
        print("✅ Token 續期成功並已更新存檔！")
        
    return creds
解法 C

OAuth Code 快捷重新授權驗證腳本 (Fast Re-auth Fallback)

若 Token 已超過 7 天遭到 Google 強制失效，可透過備份的 client_secrets.json（內含 client_id 與 client_secret），執行快捷認證腳本，只需在瀏覽器開啟驗證網址授權後，複製 URL 中的 code 貼回程式，即可 3 秒內重新產生最新的 yt_token.json：

from google_auth_oauthlib.flow import InstalledAppFlow

# 使用原本的 client_secrets.json 重新換取 Token
flow = InstalledAppFlow.from_client_secrets_file('client_secrets.json', SCOPES)
flow.redirect_uri = 'http://127.0.0.1:8080/'

# 取得授權網址
auth_url, _ = flow.authorization_url(prompt='consent', access_type='offline')
print(f"請在瀏覽器開啟授權網址:\n{auth_url}")

# 使用使用者貼回的 code 直接完成交換
auth_code = input("請貼上瀏覽器回傳 URL 中的 code 參數值: ")
flow.fetch_token(code=auth_code)

with open('yt_token.json', 'w', encoding='utf-8') as f:
    f.write(flow.credentials.to_json())
print("🎉 成功重新產生 yt_token.json！")

10. 【跨電腦移植】在另一台電腦上安裝與使用本技能

若您需要換一台全新電腦（Windows）操作本自動化技能，請依循以下 4 個簡單步驟設定：

步驟 1

安裝核心依賴軟體 (Python & FFmpeg)

  • Python 3.10+：請先下載並安裝 Python，勾選 Add python.exe to PATH。
  • FFmpeg：下載 FFmpeg 解壓縮後，將 bin 目錄路徑加入 Windows 系統環境變數 PATH 中（確保命令列可直接執行 ffmpeg 與 ffprobe）。
步驟 2

一鍵安裝 Python 第三方套件

開啟命令提示字元 (cmd) 或 PowerShell，執行以下指令安裝所需套件：

pip install faster-whisper opencc-python-reimplemented Pillow google-api-python-client google-auth-httplib2 google-auth-oauthlib
步驟 3

複製技能檔與認證金鑰

在新電腦上建立工作目錄（如 d:\影片編輯），並將舊電腦上的以下檔案複製過來：

  • SKILL.md 及技能專案資料夾（放置於 edit/episodes/teaching-video-pipeline/）
  • client_secrets.json 與 yt_token.json（Google OAuth 授權憑證）
步驟 4

放入原始影片並啟動自動化流程

將新錄製的課堂 MP4 影片放入該目錄，執行一鍵自動化處理腳本：

python process_1150907_ai_course.py

腳本將全自動完成：語音辨識 → 繁體化 → 單行長句字幕重構 → 1080p 動態片頭繪製 → 硬字幕壓製 → YouTube API 發布與播放清單建置！
